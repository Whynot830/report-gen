# reportgen

Генератор отчётов по практическим работам (docx, ГОСТ-оформление) из Python-пейлоадов. Титульный лист копируется из шаблона коллеги, дальше собираются содержание, заголовки, таблицы, рисунки и список литературы.

## Установка

Клонируйте репозиторий **внутрь папки семестра** (рядом с папками дисциплин), чтобы относительные пути к шаблонам и готовым отчётам совпали:

```bash
cd ~/Desktop/uni/3sem
git clone <url> reportgen
python3 -m pip install -r reportgen/requirements.txt
```

Нужен Python 3.11+ и готовый `.docx`-шаблон с титульным листом (до строки «Москва 2026»).

## Запуск

Из корня семестра:

```bash
python3 -m reportgen --help
python3 -m reportgen isad-pr1
python3 -m reportgen isad-pr1 isad-pr2
python3 -m reportgen all
```

После сборки в Word: правый щелчок по содержанию → **Обновить поле**.

## Пейлоады

| Имя | Дисциплина | Работа |
| --- | --- | --- |
| `pr1` / `sadd-pr1` | Архитектура, проектирование и разработка программных средств | ПР1 |
| `pr2` / `sadd-pr2` | то же | ПР2 |
| `isad-pr1` | Проектирование архитектуры информационных систем | ПР1 |
| `isad-pr2` | то же | ПР2 |

Новый отчёт: скопируйте файл в `payloads/`, добавьте его в `payloads/__init__.py`, укажите в `meta` пути к шаблону и выходному файлу.

Схемы для ПрАИС: `python3 reportgen/assets/isad/render_diagrams.py`.
